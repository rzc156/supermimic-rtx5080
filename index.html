Important caveat

This run uses anchor-relative observations (93-dim proprio + 9-dim anchor pose). The paper's Table A.1 lists only the 93-dim proprio observation. The independent reproduction found that the paper's observation alone drifts on 220 s LAFAN1 clips and saturates around 0.556–0.582; this motivates a matched local Run A rather than a causal claim about the paper. Details in REPRODUCTION_ANALYSIS.md.
