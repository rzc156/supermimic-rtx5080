## 8. 世界模型（§3.2，p.5）

- 动机：模拟器动力学已知但不提供梯度；世界模型是可微代理，提供 BPTT 需要的预测与雅可比。[明确]
- 确定性模型；以每回合 sim context ξ 为条件；预测无噪观测 ō_t。[明确]
- 组成：
  - ŝ_{t+1} = f_ω(ŝ_t, a_t, ξ)
  - r̂_{t+1} = r_ω(ŝ_t, a_t, g_t)
  - ō̂_t = g_ω(ŝ_t, ξ)
  - d̂_t = d_ω(ŝ_t, g_t)
  - 每个头"要么学习，要么解析计算"，解析头无损失项。[明确]
- 损失（Eq. 1）：在 k = 8 步自回归窗口上，从记录状态 ŝ_0 = s_0 出发，用记录动作滚动：
  L_WM(ω) = E_B Σ_{j=1}^{k} [ ‖ŝ_j − s_j‖² + (r̂_j − r_j)² + ‖ō̂_j − ō_j‖² + BCE(d̂_j, d_j) ]
  [明确]
- 状态损失各维的归一化/加权。**[未指明]**（原文直接写 ‖ŝ_j − s_j‖²）
- 哪些头是解析的、哪些是学习的。**[未指明]**
- 动力学网络是否用残差参数化（预测 Δs）。**[未指明]**
- 世界模型在无限长滚动中保持稳定，归因于 k 步自回归拟合让模型学会纠正自身误差（§3.3）。[明确，经验陈述]
- 8 步预测误差（Fig. 3c）"只计状态、按预定义的名义误差归一化、在策略 rollout 上在线测量"；数值 0.007–0.011。[明确] 名义误差的定义 **[未指明]**。

## 9. 策略与 critic（§3.3，p.5–6）

- 每次策略更新冻结 ω；在 H = 32 步想象 rollout 上优化 π_θ 与 V_ψ。[明确]
- 想象 rollout 起点：replay buffer 中的状态 s_0 ~ ρ_0 及其记录的 ξ。[明确]
- 每步：模型输出 ō̂_t，重新加传感器噪声，策略动作 a_t = π_θ(ō̂_t + η_t, g_t)。[明确]
- 目标（Eq. 2）：Ĵ(θ) = E[ Σ_{t=0}^{H−1} γ^t ĉ_t r̂_{t+1} + γ^H ĉ_H V_ψ(ŝ_H, g_H, ξ) ]。[明确]
- 梯度：BPTT 通过 H 步，用世界模型对 ŝ_t 与 a_t 的雅可比，一阶梯度。[明确]
- critic 目标（Eq. 3），只在想象 transition 上反向计算：
  R̂_t = r̂_{t+1} + γ(1 − d̂_{t+1}) [ (1−λ) V_{t+1} + λ R̂_{t+1} ]，R̂_H = V_H，
  L_V(ψ) = E Σ_{t=0}^{H−1} (V_t − R̂_t)²，V_t = V_ψ(ŝ_t, g_t, ξ)。[明确]
- 目标 R̂_t 每个 rollout 算一次，拟合 ψ 期间固定。[明确]
- 与 SHAC 的差异：软存活权重替代硬终止；critic 无 EMA 目标网络。[明确]
- 无 critic 的变体只优化 H 步奖励和，更短视；critic 对扰动后恢复重要（§4.3）。[明确]
- critic 的输入 ŝ_t 是否 detach（不把 critic 损失的梯度传回世界模型/策略）。**[未指明]**（ω 在策略更新内冻结；R̂ 固定；按标准做法 critic 输入 detach）
- 想象中上一动作 a_{t−1} 如何进入观测头（g_ω 的签名只有 ŝ, ξ）。**[未指明]**

## 12. 训练循环（Appendix D.1，Algorithm A.1，p.15）

每次迭代：
1. **采集**：策略加动作噪声在模拟器中 rollout，transition 推入 B，替换最旧的；重置起点按"基于回报的采样"。
2. **拟合世界模型**：从 B 采 k 步窗口，用记录动作自回归滚动 f_ω，ω ← ω − α_ω ∇_ω L_WM。
3. **改进策略**：采一个接口 i ~ p(I) 和 B 中的起始状态；通过固定的 f_ω 在策略上想象 H 步：ŝ_{t+1} = f_ω(ŝ_t, π_i(ō̂_t + η_t, g_t), ξ)；θ ← θ + α_θ ∇_θ Ĵ_i；再用想象 rollout 的 GAE 目标拟合 V_ψi。

- ω 与 θ 每次迭代都更新；ω 只在策略反传时 stop-gradient。[明确]
- 下游接口的 Ĵ_i 只更新其编码器 enc_θ,i。[明确]
- 早期策略的 transition 对世界模型拟合仍有效，因为动力学不依赖采集策略。[明确]

**基于回报的重置采样（D.1）**[明确]：
- 动作时间线分成 1 s 的 bin；每个 bin b 维护从该 bin 出发的折扣回报运行估计 G_b，用策略自己的 rollout 更新。
- 重置混合三种分布：50% 在 bin 上均匀；40% 按 softmax_b(−25 G_b / G_max)，G_max 为可达到的最大折扣回报；10% 按各 bin 过去的 softmax 权重比例（让学会的难动作保留练习）。
- G_b 的更新规则（EMA 系数、用哪些步的回报）。**[未指明]**
- G_max 的具体计算。**[未指明]**
- bin 内起点是否均匀、重置时是否加姿态噪声。**[未指明]**

## 15. 实验协议与数值结果（§4，p.6–8）

## 16. 多接口与速度接口（Appendix B、G，Table A.6）

**多接口（Appendix B）**[明确]：
- 每个接口 i 一个 POMDP M_i，有自己的目标空间、奖励、终止、critic V_ψi。
- 单个策略网络：z = enc_θ,i(g) ∈ Z，a = dec_θ(z, o)。目标 max_θ E_{i~p(I)} [Ĵ_i(θ)]。
- 所有接口共用同一个 f_ω，不按接口重训。
- 下游接口由蒸馏或 RL 训练：蒸馏用动作跟踪奖励，命令从参考动作读取；RL 直接通过世界模型优化接口自己的任务奖励。
- 下游接口 rollout 上，回报梯度经共享解码器传到该接口编码器，解码器权重 stop-gradient；解码器仍由动作跟踪目标训练。
- RL 速度编码器另有一个 latent 对齐损失（权重 0.1，MSE，朝向动作编码器在同一步的 latent，对动作 latent stop-gradient；仅在参考命令的 rollout 上）。

**速度接口训练设置（Appendix G.1）**[明确]：
- 命令 g_t = (v_x, v_y, ω_z)：航向（仅 yaw）系中的目标平面根速度 + 世界系目标偏航率。
- 参考命令：参考根速度在参考航向系中的 25 帧中心均值。
- 每个编码器单独一次 run 从头训练，与动作跟踪接口联合训练 100,000 次迭代；数据为 LAFAN1 与 BONES-SEED 过滤出的走/跑库。
- 4096 环境中一半、每个想象批中一半用速度接口，p(I) 均匀；每个想象批混合两个接口（与 Algorithm A.1 每次更新采一个接口不同）。
- RL 编码器的命令源：每次重置和每 250 步（5 s）重采样；0.5 概率每步从参考 clip 读命令，否则保持一个均匀采样的命令：v_x ∈ [−1.5, 2] m/s，v_y ∈ [−1.32, 1.32] m/s，ω_z ∈ [−3.35, 3.35] rad/s，0.1 概率置零（站立）。
- 速度 rollout 用速度跟踪奖励和仅摔倒终止（Table A.6）；蒸馏基线用动作跟踪奖励和终止。

**速度奖励（Table A.6）**，每项乘 Δt = 0.02 s：

| 项 | 公式 | 权重 |
|---|---|---|
| 线速度 | exp(−‖v_xy − v_xy^cmd‖² / 0.5²) | 2.0 |
| 偏航率 | exp(−(ω_z − ω_z^cmd)² / 0.5) | 2.0 |
| 动作平滑 | ‖a_t − a_{t−1}‖² | −0.3 |
| 关节限位 | 同 Table A.2 | −2 |
| 躯干侧倾 | sin² φ_torso（前倾不罚） | −4 |
| 躯干滚转/俯仰角速度 | ω_roll² + ω_pitch² | −0.05 |
| 终止（摔倒） | h_root < 0.35 m 或 1 + u_z > 0.7（约 73°） | – |

**阶跃测试（G.2）**[明确]：从站立给固定命令 5 s，每命令 4 次；相对稳态误差 = 最后 2 s 平均速度误差范数 / 命令范数，根速度在航向系测；取未摔倒试次的中位数；三个平面各 15×15 网格共 672 个命令（去掉站立命令）；误差 > 0.9 画为 0.9。结果：RL 650 胜，蒸馏 15 胜；中位误差 0.16 vs 0.49；蒸馏在 7 个"平移与 ≥ 2.8 rad/s 转弯**组合**"的命令上全部摔倒（"all combining translation with a turn of at least 2.8 rad/s"）。每个策略一个种子。
